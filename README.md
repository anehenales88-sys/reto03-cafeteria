
# Cafetería Aroma

Cafetería Aroma es un proyecto educativo que consiste en una landing page para presentar una cafetería ficticia. La página muestra una presentación del negocio, algunos productos de su carta y la información de contacto y horario.

## Cómo abrir el proyecto

Para visualizar la página, hay que abrir el archivo `index.html` con un navegador web, como Google Chrome o Microsoft Edge. No es necesario instalar ningún programa adicional ni utilizar un servidor.

## Contenido del repositorio

- `index.html`: contiene la estructura, los estilos y el contenido de la landing page.
- `README.md`: explica el objetivo del proyecto y cómo visualizarlo.
- `.gitignore`: indica los archivos que Git debe ignorar.

## Mejoras pendientes

## Estado del proyecto

La landing está publicada como una página estática y se puede abrir directamente en un navegador. Actualmente contiene una presentación, una carta de productos y un apartado de contacto y horario.
